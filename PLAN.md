# План Pxbit

Цель: P2P-платформа для сделок, собранных из шагов. На каждом шаге видно, кто что должен сделать, к шагу можно прикрепить файлы и другие артефакты, а сделку можно сохранить как шаблон. Расчёты идут в USDT, как на P2P-криптобиржах, только сделки бывают любыми, а не только обменом денег.

Мы идём по этапам сверху вниз. Этап считается закрытым, когда выполнены все его пункты и проходит `npm run check`.

## Принятые решения

- **Баланс хранится только в USDT.** Фиат используется только для отображения. Сервер отдаёт суммы строками (`"1250.500000"`), клиент не превращает их в `number`.
- **Конвертация округляет вниз**, чтобы пользователь никогда не видел больше денег, чем у него есть.
- **Валюта отображения — это настройка профиля на сервере** (`PATCH /me/settings`), а не `localStorage`. Так выбор одинаков на всех устройствах.
- **Моки подключаются на уровне `baseQuery`.** Чтобы перейти на настоящий API, выключите `NEXT_PUBLIC_API_MOCKS`, а когда моки станут не нужны, удалите папку `src/mocks`.
- **Ответы API проверяются zod-схемами** через `responseSchema` в RTK Query, поэтому расхождение с бэкендом сразу видно как ошибка.
- **Вход только через внешних провайдеров (OAuth 2.0 / OIDC)**, своих паролей нет. Фронт не видит токенов провайдера: он передаёт `code` и `state` бэкенду, а тот ставит свою cookie сессии.
- **`proxy.ts` проверяет только наличие cookie**, а валидность сессии решает API (ответ 401). Поэтому cookie должна стоять на общем с фронтом домене.
- **Выход и истёкшая сессия делают полную перезагрузку страницы**, чтобы в памяти не осталось данных прошлого пользователя.

## Контракт API (сейчас на моках)

Полное описание лежит в `docs/openapi.yaml`, здесь только кратко:

| Метод и путь                     | Что делает                                              |
| -------------------------------- | ------------------------------------------------------- |
| `POST /auth/{provider}/start`    | `{ redirectUri }` → `{ authorizeUrl }`                  |
| `POST /auth/{provider}/callback` | `{ code, state, redirectUri }` → `User` + cookie сессии |
| `POST /auth/logout`              | снимает cookie                                          |
| `GET /me`                        | `{ id, nickname, avatarUrl, displayCurrency }`          |
| `PATCH /me/settings`             | `{ displayCurrency }` → `User`                          |
| `GET /me/balance`                | `{ asset: "USDT", available, locked }`, суммы строками  |
| `GET /rates`                     | `{ base: "USDT", rates: { RUB, CNY, USD }, updatedAt }` |
